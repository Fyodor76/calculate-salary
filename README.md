# zp-payroll

Калькулятор выплат по вашей инструкции (Точка / Контур.Эльба / ЕНС).

1. Выбираете: **Аванс / ЗП / Премия**
2. Вбиваете начисление
3. Шаги: выплата в Точке → отчёт НДФЛ в Точке (Бухгалтерия) → проверка в Эльбе → ЕНС

```bash
cd zp-payroll
npm install --registry https://registry.npmjs.org/
npm run dev
```
